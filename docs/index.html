aMule Remote

Informativa sulla privacy · Privacy Policy
Ultimo aggiornamento / Last updated: 11 agosto 2026

🇮🇹 Italiano

aMule Remote non raccoglie, non memorizza e non trasmette alcun dato personale.

  • L'app è un telecomando per un server aMule (amuled) di proprietà dell'utente. Si connette esclusivamente all'indirizzo del server che l'utente stesso inserisce.
  • L'indirizzo del server e la password di accesso sono salvati solo sul dispositivo dell'utente, nel Portachiavi (Keychain) di iOS/iPadOS, protetti dal sistema operativo.
  • Nessun dato viene inviato agli sviluppatori dell'app o a terze parti.
  • L'app non contiene pubblicità, non utilizza strumenti di analisi (analytics), non traccia l'utente e non richiede la creazione di alcun account.
  • L'unica comunicazione di rete avviene tra il dispositivo dell'utente e il server aMule indicato dall'utente, tramite il protocollo External Connections (EC) di aMule.
  • L'app non scarica file sul dispositivo e non contiene alcun catalogo di contenuti.

Per qualsiasi domanda è possibile aprire una issue sul repository del progetto.

🇬🇧 English

aMule Remote does not collect, store, or transmit any personal data.

  • The app is a remote control for a user-owned aMule server (amuled). It connects exclusively to the server address entered by the user.
  • The server address and access password are stored only on the user's device, in the iOS/iPadOS Keychain, protected by the operating system.
  • No data is sent to the app developers or to any third party.
  • The app contains no advertising, uses no analytics, does not track the user, and requires no account.
  • The only network communication happens between the user's device and the user-specified aMule server, via aMule's External Connections (EC) protocol.
  • The app does not download files to the device and contains no catalog of content.

For any questions, please open an issue on the project repository.
