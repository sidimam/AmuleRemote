# Privacy Policy — aMule Remote

**Last updated / Ultimo aggiornamento: September 9, 2026**

## English

**aMule Remote does not collect, store, or transmit any personal data.**

- The app is a remote control for a **user-owned** aMule server (amuled). It connects exclusively to the server address entered by the user.
- The server address and access password are stored **only on the user's device**, in the iOS / iPadOS / visionOS / tvOS / macOS Keychain, protected by the operating system.
- **Optional iCloud sync** (off by default): if the user turns it on, server profiles are stored in the user's own iCloud account (iCloud Key-Value Storage) and passwords in the user's iCloud Keychain. This data is handled exclusively by Apple's iCloud infrastructure under the user's Apple Account; the developer has no access to it. Turning the option off keeps the data on the device only.
- No data is sent to the app developers or to any third party.
- The app contains no advertising, uses no analytics, does not track the user, and requires no account.
- The only network communication happens between the user's device and the user-specified aMule server, via aMule's External Connections (EC) protocol.
- Notifications are generated locally on the device; no push server is involved. The Apple Watch app only receives data from the paired iPhone.
- The app does not download files to the device and contains no catalog of content.

For questions: open an issue on this repository.

## Italiano

**aMule Remote non raccoglie, memorizza né trasmette alcun dato personale.**

- L'app è un telecomando per un server aMule (amuled) **di proprietà dell'utente**. Si connette esclusivamente all'indirizzo del server che l'utente stesso inserisce.
- L'indirizzo del server e la password di accesso sono salvati **solo sul dispositivo dell'utente**, nel Portachiavi (Keychain) di iOS / iPadOS / visionOS / tvOS / macOS, protetti dal sistema operativo.
- **Sincronizzazione iCloud facoltativa** (disattivata di default): se l'utente la attiva, i profili server sono salvati nel suo account iCloud (iCloud Key-Value Storage) e le password nel suo Portachiavi iCloud. Questi dati sono gestiti esclusivamente dall'infrastruttura iCloud di Apple sotto l'Account Apple dell'utente; lo sviluppatore non vi ha accesso. Disattivando l'opzione i dati restano solo sul dispositivo.
- Nessun dato viene inviato agli sviluppatori dell'app o a terze parti.
- L'app non contiene pubblicità, non usa strumenti di analisi (analytics), non traccia l'utente e non richiede la creazione di alcun account.
- L'unica comunicazione di rete avviene tra il dispositivo dell'utente e il server aMule indicato dall'utente, tramite il protocollo External Connections (EC) di aMule.
- Le notifiche sono generate localmente sul dispositivo, senza alcun server push. L'app per Apple Watch riceve i dati solo dall'iPhone abbinato.
- L'app non scarica file sul dispositivo e non contiene alcun catalogo di contenuti.

Per domande: apri una issue su questo repository.
